IANA timezone rules: IANA Time Zone Database, https://www.iana.org/time-zones,
via pinned Python tzdata 2026.5 (IANA version recorded in each run).
IANA timezone data is public domain; see https://data.iana.org/time-zones/tz-link.html.

Treat the enriched exported airport catalog conservatively as an ODbL-derived
database. Before public use, provide visible attribution and a working means to
obtain the relevant machine-readable derivative database (or alteration files as
applicable), including this notice, the input/version manifest, transformation
code and the applicable license/access terms. Do not claim the entire enriched
catalog is public domain. Exact ODbL obligations depend on distribution/public
use; review them before publishing. Do not include credentials in any release.
